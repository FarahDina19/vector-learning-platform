Pesawat Terbang - Halaju Paduan
Pesawat terbang 300 km/j ke Utara, tetapi angin bertiup 50 km/j ke Timur. Arah sebenar pesawat (paduan) berbeza dari arah yang dimaksudkan! Vektor membantu pilot mengira laluan yang tepat untuk sampai ke destinasi. Ini adalah penambahan dua vektor halaju.

Pembinaan Bangunan - Daya Paduan
Dua kabel berkait pada hook untuk mengangkat beban berat. Satu kabel tarik dengan daya 800 N pada 30° dari mendatar, satu lagi 600 N pada 45°. Jurutera harus kira vektor daya paduan untuk memastikan struktur selamat dan tidak runtuh. Ini melibatkan penambahan vektor daya 2D.

Dalam permainan, setiap karakter, peluru, dan objek mempunyai vektor kedudukan (position) dan vektor halaju (velocity). Setiap bingkai permainan, halaju ditambah ke kedudukan untuk mengira kedudukan baru. Grafiknya perlu menampilkan sudut dan arah dengan tepat menggunakan trigonometri vektor.

Skalar vs Vektor (5.1)

Ketahui perbezaan asas yang memisahkan skalar dari vektor

🔢
Skalar (Scalar)
Definisi: Kuantiti yang hanya mempunyai magnitud (saiz) sahaja. Tiada arah. Diwakili oleh satu nombor positif atau negatif.

Contoh dalam kehidupan:
• Suhu: 25°C (hanya ada nilai)
• Laju: 50 km/h (hanya ada kelajuan)
• Jisim: 2 kg (hanya ada berat)
• Masa: 5 jam
• Tekanan: 100 Pa (Pascal)
Hanya Magnitud Tiada Arah
➡️
Vektor (Vector)
Definisi: Kuantiti yang mempunyai magnitud DAN arah. Kedua-dua unsur penting untuk melukiskan dengan lengkap. Dilambangkan dengan anak panah atau huruf tebal.

Contoh dalam kehidupan:
• Halaju: 50 km/h Utara (ada arah bergerak)
• Daya: 500 N ke bawah (ada arah tindakan)
• Sesaran: 100 m ke Timur (ada arah pergerakan)
• Pecutan: 10 m/s² ke hadapan
Magnitud + Arah Kritis untuk operasi
📊
Magnitud
Skalar: Ya saja (25°C)
Vektor: Ya + Arah (50 km/h Utara)
🧭
Arah
Skalar: Tidak ada
Vektor: Penting (Utara, Timur, dll)
➕
Penambahan

Vektor: Guna Segitiga/Segiempat
🔤

⚡

🎯

Vektor: Halaju, Daya, Sesaran
🎯
Jenis-jenis Vektor
Vektor Null (Sifar): Vektor dengan magnitud sifar, tiada panjang dan tiada arah yang ditakrifkan. Dilambangkan sebagai 0 atau 𝟎.

Vektor Unit: Vektor yang mempunyai magnitud tepat 1 unit. Unit vektor arah x ialah i = (1, 0) dan arah y ialah j = (0, 1).

Vektor Selari (Parallel): Dua vektor A dan B adalah selari jika A = kB untuk beberapa skalar k ≠ 0. Mereka mempunyai arah sama (k > 0) atau bertentangan (k < 0), tetapi magnitud mungkin berbeza. Contoh: Jika A = 2i + 4j dan B = i + 2j, maka A = 2B (selari).

Vektor Sama (Equal): Dua vektor A dan B adalah sama jika mereka mempunyai komponen-i dan komponen-j yang tepat sama: A_x = B_x DAN A_y = B_y. Arah sama DAN magnitud sama, walaupun kedudukan pangkal berlainan.

Vektor Negatif: Negatif vektor A (ditulis −A) mempunyai magnitud yang sama tetapi arah bertentangan. Jika A = 3i + 4j, maka −A = −3i − 4j.
Sederhana - Penting

Penambahan & Pengurangan Vektor (5.3)

Dua kaedah untuk menambah vektor: Hukum Segitiga dan Hukum Segiempat Selari

△
Hukum Segitiga (Triangle Law)
Penyataan Formal: Untuk menambah dua vektor A dan B, lukis A dari titik O, kemudian dari hujung A, lukis B. Vektor paduan adalah garis lurus dari O ke hujung B.

Langkah-langkah:
1. Lukis vektor A dari O ke titik pertengahan
2. Dari hujung A, lukis vektor B
3. Vektor paduan: Garis lurus dari O ke hujung B
Hasil Akhir: A + B = C

Contoh: Jika A = 3i + 4j dan B = 2i − 1j, maka A + B = 5i + 3j
Sederhana - Sering Digunakan
▭
Hukum Segiempat Selari (Parallelogram Law)
Penyataan Formal: Untuk menambah dua vektor A dan B, lukis kedua-duanya dari titik O yang sama. Lengkapkan segiempat selari dengan kedua vektor sebagai sisi bersebelahan. Pepenjuru dari O adalah vektor paduan.

Langkah-langkah:
1. Lukis A dan B dari O
2. Dari hujung A, lukis garis selari dengan B
3. Dari hujung B, lukis garis selari dengan A
4. Pepenjuru utama = vektor paduan A + B
Hasil Akhir: Sama dengan hukum segitiga
Sederhana
➕
Penambahan Algebra
Formula:
(A_x + B_x)i + (A_y + B_y)j

Contoh:
(3i+4j) + (2i-1j) = 5i+3j
Mudah
➖
Pengurangan
Formula:
(A_x − B_x)i + (A_y − B_y)j

Ingat: A - B = A + (-B)
Sederhana

📝 Langkah-langkah Menambah Vektor:

  1. Langkah 1: Tulis vektor dalam bentuk xi + yj
  2. Langkah 2: Tambah komponen i dengan komponen i
  3. Langkah 3: Tambah komponen j dengan komponen j
  4. Langkah 4: Tulis jawapan sebagai vektor baru
  5. Langkah 5: Lukis gambar untuk sahkan jawapan
🔑
Sifat-sifat Penambahan & Pendaraban Vektor (Vector Algebra)
1. Komutatif: A + B = B + A (urutan tidak penting dalam penambahan)
2. Asosiatif: (A + B) + C = A + (B + C) (pengelompokan tidak penting)
3. Identiti Penambahan: A + 0 = A (menambah vektor sifar tidak mengubah vektor)
4. Songsang Penambahan: A + (−A) = 0 (vektor dan negatifnya menghasilkan sifar)

5. Komutatif Pendaraban Skalar: k₁(k₂A) = k₂(k₁A) = (k₁k₂)A
6. Distributif ke Vektor: k(A + B) = kA + kB (skalar boleh diagihkan)
7. Distributif ke Skalar: (k₁ + k₂)A = k₁A + k₂A (skalar boleh diagihkan)
8. Identiti Pendaraban: 1 × A = A (skalar 1 tidak mengubah vektor)

Sumber dan Petua 💡

Rujukan cepat, kesilapan biasa, dan formula penting

⚠️
Kesilapan Biasa dan Cara Mengelaknya
❌ KESILAPAN 1: Mencampurkan Komponen
Salah: "3i + 4j = 7"
✓ Betul: Vektor 3i + 4j adalah DUO komponen, bukan satu nombor. Magnitud ialah √(3² + 4²) = 5

❌ KESILAPAN 2: Menambah Magnitud Terus
Salah: "Untuk tambah A + B, cukup tambah |A| + |B|"
✓ Betul: Mesti gunakan hukum segitiga (tail-to-head) atau segiempat selari. Contoh: (3i+0j) + (0i+4j) = 3i+4j dengan |hasil| = 5, bukan 7

❌ KESILAPAN 3: Salah Tafsir Negatif
Salah: "−3i bermakna tiada komponen i"
✓ Betul: −3i bermakna 3 unit dalam arah NEGATIF i (ke Barat). Komponen x = −3, bukan 0

❌ KESILAPAN 4: Salah Kesamaan Vektor
Salah: "Vektor A = 2i+3j dan B = 2i+3j sama dengan kedudukannya berlainan"
✓ Betul: A dan B ADALAH sama! Vektor sama jika komponen sama, kedudukan pangkal boleh berbeza

❌ KESILAPAN 5: Salah Parallel
Salah: "A = 4i+2j dan B = 2i+j tidak selari kerana tiada skalar k"
✓ Betul: A = 2B, jadi A dan B ADALAH selari dengan k = 2. Kira nisbah: (4/2) = (2/1) = 2 ✓
📐
Formula Penting dan Takrifan Matematik
NOTASI: Huruf tebal (A, B, v) menandakan vektor; i dan j ialah vektor unit asas. A_x dan A_y ialah komponen skalar vektor A. |A| atau ‖A‖ menandakan magnitud.

BENTUK VEKTOR:
• Bentuk Komponen: v = xi + yj = x(1,0) + y(0,1)
• Bentuk Pasangan: v = (x, y)
• Bentuk Kolom: v = [x / y]

MAGNITUD DAN ARAH:
• Magnitud: |v| = √(x² + y²) (panjang vektor)
• Arah: θ = atan2(y, x) (sudut dari paksi x positif, lawan jam)
• Unit Vektor: û = v / |v|, bagi v ≠ 0 (arah dengan magnitud 1)

OPERASI VEKTOR:
• Penambahan: A + B = (A_x + B_x)i + (A_y + B_y)j
• Pengurangan: A − B = (A_x − B_x)i + (A_y − B_y)j
• Pendaraban Skalar: kv = (kx)i + (ky)j, k adalah skalar
• Magnitud kv: |kv| = |k| × |v|

JENIS VEKTOR:
• Vektor Sama: A = B ⟺ A_x = B_x AND A_y = B_y
• Vektor Selari: A ∥ B ⟺ A = kB dengan k ≠ 0 (kedua-dua bukan sifar)
• Vektor Songsang: −A mempunyai magnitud |A| dengan arah bertentangan
• Vektor Sifar: 0 = 0i + 0j (tiada arah)
📚
Rujukan Cepat & Teknik Penyelesaian
WARNA SISTEM KOD DALAM GAMBAR:
🔵 Biru = Komponen i (arah x, Timur/Barat)
🔴 Merah = Komponen j (arah y, Utara/Selatan)
🟢 Hijau = Vektor paduan (hasil akhir)

PERBEZAAN SKALAR vs VEKTOR:
• Skalar: Magnitud sahaja (25°C, 50 km/h, 5 kg)
• Vektor: Magnitud + Arah (50 km/h Utara, 500 N ke bawah)

TEKNIK KOMPONEN:
1. Bahagi vektor kepada komponen i (mendatar) dan j (menegak)
2. Operasi: Lakukan pada setiap komponen secara berasingan
3. Gabung: Tulis semula sebagai bentuk xi + yj

OPERASI ASAS:
• Penambahan: Tambah i dengan i, j dengan j ➜ A + B = (A_x+B_x)i + (A_y+B_y)j
• Pengurangan: Tolak i dengan i, j dengan j ➜ A − B = (A_x−B_x)i + (A_y−B_y)j
• Pendaraban: k(xi+yj) = kxi + kyj (darab setiap komponen dengan k)

ANALISIS VEKTOR:
• Magnitud: Gunakan Teorem Pythagoras |v| = √(x² + y²)
• Arah: Gunakan tangen songsang tan⁻¹(y/x), perhatian kepada kuadran
• Parallelogram: Untuk visualisasi penambahan vektor dua vektor
